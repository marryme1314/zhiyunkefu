本目录为题目要求的「数据库初始化脚本」（建表语句 + 初始数据说明）。

## 文件

- `init.sql`：建库建表（含角色、意图、知识库分区字段），与当前业务模型一致。

## 推荐运行方式

1. **Docker Compose**（根目录 `docker-compose.yml` + `初始化数据库.bat`）起 MySQL 后，由 Spring Boot **Flyway**（`src/main/resources/db/migration/`）自动迁移建表。
2. 若手工执行本目录 `init.sql` 建表，请将 `application.yml` 中 `spring.flyway.enabled` 设为 `false`，避免与 Flyway 冲突。

## 初始数据如何产生

不在 SQL 里写入密码哈希，避免脚本过期；启动应用后自动初始化：

| 数据 | 来源 |
|---|---|
| 管理员账号 `admin@company.com` / `Admin123!` | `AdminBootstrap` |
| 示例知识库 3 篇（产品介绍 / FAQ / 退换货政策） | `resources/seed/` + `KnowledgeBootstrap` |

因此「初始数据」= SQL 建表结构 + 应用启动时的种子逻辑，满足本地开箱可问答。
